# История изменений (Changelog)

Все заметные изменения в проекте документируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и проект придерживается [Семантического версионирования](https://semver.org/lang/ru/).

## [1.1.0] - В разработке (Unreleased)

### Добавлено
- **Поддержка одиночных файлов и фильмов в корне раздач**:
  - Сканирование и обработка одиночных видеофайлов (фильмов и серий), лежащих напрямую в папках раздач без отдельных подпапок.
  - Автоматическое определение полнометражных фильмов по ключевым словам (`movie`, `фильм`, `gekijouban`, `eiga`) и метаданным провайдеров (Shikimori / AniList / AniDB).
  - Размещение фильмов во вложенную директорию `Films/` внутри папки аниме с формированием чистого и безопасного имени файла.
  - Автоматическое связывание фильма с корневой папкой франшизы (например, *«Чёрный клевер: Меч короля магов»* → `Чёрный клевер/Films/` или *«Поезд «Бесконечный»»* → `Клинок, рассекающий демонов/Films/`), в том числе при отсутствии других сезонов сериала.
- **Динамическая проверка версий и обновлений**:
  - Добавлен REST-эндпоинт `/api/version` с фоновой проверкой свежих релизов на GitHub (`internal/updater`).
  - Живой индикатор актуальности версии в нижней части сайдбара с уведомлением о новых релизах (`v1.0.0 → v1.1.0 🔥`).
  - Панель «О программе и обновления» в настройках с кнопкой ручной проверки и инструкциями по обновлению.
- **Поддержка Windows и мультиплатформенные бинарники**:
  - Полноценная поддержка компиляции `.exe` бинарников под Windows (`x64` и `ARM64`).
  - Автоматическая публикация архивов `.zip` / `.tar.gz` со всеми платформами и файлом контрольных сумм `checksums.txt` (SHA-256) в GitHub Releases.
- **Переход на GitHub Container Registry (GHCR)**:
  - Публикация официальных Docker-образов переведена на `ghcr.io/jellyanli/jellyanli`.
  - Мультиархитектурная сборка под `linux/amd64` и `linux/arm64` с нативной кросс-компиляцией Go без медленной QEMU-эмуляции.
- **Расширенные инструменты сборки**:
  - Команды `make build-windows`, `make build-all` и обновленный скрипт `build.sh` для быстрого билда под любые ОС.
- **Шаблоны сообщества и локализация**:
  - Русскоязычные шаблоны сообщений об ошибках (`bug_report.md`), предложений (`feature_request.md`), шаблон Pull Request и полное руководство `CONTRIBUTING.md`.

### Изменено
- **Бесшумная фоновая синхронизация**:
  - Фоновый таймер больше не засоряет журнал строками «Библиотека актуальна», если изменений нет. При появлении новых файлов или ошибок отчёт выводится как обычно.
- **Управление памятью и временем жизни предпросмотра (Dry-Run)**:
  - Автоматическая очистка старого дерева предпросмотра при повторном запуске.
  - Фоновый таймер автоочистки результатов предпросмотра из памяти через 15 минут.
- **Полная автономность в локальной сети**:
  - Удалены внешние запросы к Google Fonts (`fonts.googleapis.com`), применён стек быстрых системных шрифтов без обращений в интернет.

### Исправлено
- **Нормализация русских названий (`ё` / `е`)**:
  - Исправлена нормализация строк, из-за которой буква `ё` не учитывалась в диапазоне алфавита, приводя к несовпадению одинаковых названий (*«Чёрный клевер»* и *«Черный клевер»*).
- **Отображение рамок в светлой теме**:
  - Исправлено исчезновение границ карточек (`.card:hover`) при наведении курсора в светлой теме благодаря введению переменной `--border-hover`.
- **Изоляция дерева файлов в веб-интерфейсе**:
  - Интерактивное дерево теперь гарантированно строит структуру только по последней сессии предпросмотра без дублирования веток.

## [1.0.0] - 2026-08-23

### Добавлено
- Сканирование нескольких папок с торрент-раздачами одновременно.
- Автоматическое связывание франшиз аниме, определение сезонов и выравнивание сквозной нумерации серий.
- Привязка внешних аудиодорожек (`.mka`, `.flac`, `.ac3`) и субтитров (`.ass`, `.srt`) с автоматической подстановкой языковых тегов.
- Интеграция с API Shikimori, AniList и AniDB для получения названий на русском языке и построения дерева сезонов.
- Режим относительных символических ссылок для Docker, Synology NAS, Unraid и CasaOS/ZimaOS.
- Веб-интерфейс в реальном времени с интерактивным деревом файлов, SSE-стримингом логов и выбором папок на сервере.
- Фоновый демон периодической синхронизации с настраиваемым интервалом.
- Безопасный режим предпросмотра изменений (Dry-Run) через веб-панель и командную строку.
- Мультиархитектурный Docker-образ (`linux/amd64`, `linux/arm64`).
- Набор unit-тестов с оффлайн-кэшем для проверки всех алгоритмов сопоставления.
